🚀 ИНСТРУКЦИЯ ПО ЗАПУСКУ СЕРВЕРА

Для запуска эмулятора сервера Karos Online необходимо выполнить следующие действия строго по порядку:

ШАГ 1 — НАСТРОЙКА КЛИЕНТА

Запустить файл:

setup_client.bat

ШАГ 2 — ЗАПУСК DEV-СЕРВЕРА

После завершения первого этапа запустить:

start_dev.bat

ШАГ 3 — ЗАПУСК AMO LOCAL

Последним запустить файл:

AMo-local.cmd

ВАЖНО: Соблюдайте указанную последовательность запуска файлов.
